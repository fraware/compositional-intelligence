Agreement is one test. Adequacy is another.

A finite illustration accompanying Functorial Consistency

Suppose a source artifact is a subset of {1, 2, 3, 4}. Its target representation records the even members. A source-side transformation adds the odd element 1. The corresponding target-side transformation is the identity, since the even members should remain unchanged.

Two routes through this transformation problem should agree. An independent reference checks whether each translation preserves the intended target content. Those are distinct questions.

What the comparison establishes

Here X is the power set of {1, 2, 3, 4}. The source operation is f(x) = x ∪ {1}. The reference translation is E(x) = {n ∈ x : n is even}, and the target operation g is the identity. The acceptance relation R is exact set equality. All displayed targets are well-typed sets of even members of the finite universe.

The faithful rule sets T0 = T1 = E. The collapsed rule maps every input to the empty set on both paths. The spurious rule uses T0 = E and T1(x) = E(x) ∪ {4}. The independent adequacy check compares both translated outputs against E on their respective sources.

The collapsed rule agrees on every input, despite discarding even members for most inputs. The spurious rule passes both tests on any input already containing 4, demonstrating how a defective rule can pass particular items. Even exhaustive success in this four-element model establishes no general claim about other artifact domains or AI systems.

This is a finite pedagogical construction, not an empirical benchmark or a machine-checked theorem. The corresponding research essay discusses formation, validator provenance, unresolved outcomes, directional relations, and stronger categorical obligations beyond this example.
