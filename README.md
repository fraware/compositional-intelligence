# Compositional Intelligence

Source repository for the minimalist Compositional Intelligence website.

This repository contains public-safe website styling and release-preparation tools. It does not publish the essays or enable hosting. See [the release process](docs/RELEASE.md) for the conditions that must be satisfied before publishing.
